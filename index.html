Moin Shadab Web Harmonium is a free, open-source browser instrument inspired by the Indian harmonium — a staple of Hindustani and Carnatic classical music, bhajans, and ghazals.


Built with the Web Audio API. No plugins, no downloads, no accounts. Works on desktop and mobile. MIDI-compatible if your browser supports WebMIDI.


Features: Harmonium-style reed synthesis · Reverb · Multiple octaves · Transpose · Scale highlighting · Drone · Recorder · MIDI input · Keyboard shortcuts · Touch support
